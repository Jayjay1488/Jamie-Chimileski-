# Crystal App

A simple Crystal application that demonstrates basic project structure, documentation, and testing.

## Description

This project was created to demonstrate a fully documented Crystal repository. It includes a simple `Greeter` class that can be used to generate greetings.

## Getting Started

### Prerequisites

* [Crystal](https://crystal-lang.org/install/) must be installed.
* [Shards](https://crystal-lang.org/reference/getting_started/shards.html), the Crystal dependency manager, is included with Crystal.

### Installation

1. Clone the repository:
   ```sh
   git clone <repository-url>
   cd <repository-directory>
   ```
2. Install the dependencies:
   ```sh
   shards install
   ```

## Usage

To run the application, execute the following command:

```sh
crystal src/crystal-app.cr
```

This will compile and run the application, and you should see the output "Hello, world!".

## Running the tests

To run the tests, execute the following command:

```sh
crystal spec
```

This will run the test suite and report the results. You should see output indicating that all tests passed.
